# Reglas de negocio que deben respetarse SIEMPRE

- **Zonas Pro Venta / MAR**: Las zonas configuradas en modalidad **Pro Venta** (por defecto Maracay 06, o cualquier zona creada/configurada como Pro Venta) trabajan con notas de tipo Pro Venta (MAR y PVP). Cualquier vendedor que tenga asignada una zona Pro Venta puede emitir notas Pro Venta para los clientes de dicha zona. Maracay no es exclusiva de Juan Luis.
- **Zonas General**: Las zonas en modalidad **General** trabajan con notas de tipo **General** (GEN) y **Promoción** (PRM).
- Códigos de vendedores (3 dígitos): Sandra 001, Anais 002, Alejandra 003, Juan Luis 004 (y 005+ para nuevos).
